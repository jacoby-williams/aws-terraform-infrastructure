# AWS Terraform Infrastructure Project

This project demonstrates deploying AWS infrastructure using Terraform and Infrastructure as Code (IaC).

## Resources Created
- VPC
- Public Subnet
- Internet Gateway
- Route Table
- Security Group
- Elastic Network Interface
- Elastic IP
- EC2 Web Server

## Technologies
AWS • Terraform • EC2 • VPC • Git • GitHub

## What I Learned
- Building AWS infrastructure with Terraform
- Configuring VPC networking and internet access
- Deploying EC2 instances
- Using Git and GitHub for version control
- Protecting AWS credentials from source control

## Security
AWS credentials are not stored in this repository.
